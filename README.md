# Life

This is my personal life-management repo. I use it with AI (Claude) to organize, track, and improve my life.

## How it works

Everything is plain Markdown, organized by life area. Each AI session can read the current state of any area, help me think through it, and commit updates — so the repo becomes a living record of where I am and where I'm headed.

## Structure

| Folder | Purpose |
|---|---|
| `goals/` | What I'm working toward — yearly themes, quarterly goals, and the why behind them |
| `journal/` | Dated entries — brain dumps, wins, struggles, things worth remembering |
| `reviews/` | Weekly and monthly check-ins on how things are actually going |
| `health/` | Fitness, sleep, nutrition, habits I'm building or breaking |
| `finances/` | Budget, debts, savings targets, money goals (numbers, not account credentials) |
| `work/` | Career and business — 915 Web Design, clients, income goals, skills to build |
| `relationships/` | People who matter and how I want to show up for them |
| `projects/` | Active personal projects with next actions |
| `templates/` | Reusable templates for journal entries, reviews, and goals |

## Ground rules

- **Never commit secrets**: no passwords, account numbers, API keys, or anything that would hurt if leaked. Dollar amounts and goals are fine; credentials are not.
- **Small honest entries beat big perfect ones.** A two-line journal entry is worth more than a skipped one.
- **The weekly review is the engine.** Everything else feeds it.
